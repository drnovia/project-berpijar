| Token | Hex | Use |
| --- | --- | --- |
| Blush | `#FFF5F7` | Soft backgrounds in diagrams |
| Rose | `#FFB7C5` | Accents, badges |
| Lilac | `#E8D5FF` | Secondary highlights |
| Sky | `#B8E8FC` | Links, tech callouts |
| Ink | `#3D2C4E` | Body text on light surfaces |
