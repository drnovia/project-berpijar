# Contributing — Yayasan Berpijar (site)

## Local setup

```bash
npm install
npm run dev
```

## Principles

- Respect tone in copy: inklusif, jelas, non-sensasional.
- Place new photos in `public/berpijar/` with descriptive kebab-case names.
- Run `npm test` and `npm run lint` before submitting.

## Pull requests

Describe impact on program pages (`/program`, `/dashboard`). Attach screenshots for layout changes involving GSAP/Lenis scroll sections.
